# Private Production runtime role diagnostic (prepared, not activated)

`instrumentation.ts` registers a temporary, opt-in Next.js Node-runtime diagnostic. It creates no HTTP route, uses only the deployed Production `DATABASE_URL`, and runs only when `NEXT_RUNTIME=nodejs`, `VERCEL_ENV=production`, `VERCEL_REGION` is present, and `FUTSCOUT_VALUE_ROLE_DIAGNOSTIC=1`. There is no Preview fallback. It checks `public."PlayerEconomicCurrent"` in the catalog before querying `current_user`, `session_user`, and effective `SELECT` privilege. The transaction is `READ ONLY` and ends with `ROLLBACK`; the connection is closed. Logs contain only role names, the SELECT boolean, or a fixed failure code. Driver errors, connection strings, tokens, and query payloads are never logged.

**Not executed in this change.** Future execution requires separate authorization for a Production deployment and a temporary Production-only flag. The runtime changes are `instrumentation.ts` and `runtime-role-diagnostic.ts`; the test and this document accompany them for review. Deploy these files in an isolated release, set `FUTSCOUT_VALUE_ROLE_DIAGNOSTIC=1` only in Production for the diagnostic window, and inspect the private Vercel runtime logs with an authorized account. Vercel runs instrumentation on new server instances, so multiple identical observations are possible; a log entry proves the role for that instance, not every pooled connection globally. The query may add up to five seconds to an instance's startup if the database is unavailable, but a failure is contained and does not expose a driver error. Do not use Preview to infer Production. To remove the diagnostic after recording the result privately, remove the flag and deploy code without the temporary instrumentation and helper. No role, grant, or database migration is changed.

The existing `public."PlayerEconomicCurrent"` name was confirmed against the Production catalog in the generation preflight. An absent or renamed table fails closed. A `canSelectCurrent=false` result is a finding, not a request to change privileges automatically.
